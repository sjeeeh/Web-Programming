String Object functions

The String object in JavaScript is a built-in object used to store, manipulate, and perform operations on text (a sequence of characters). It provides methods to change case, find characters, extract parts of a string, and replace text.

text.length 
text.toUpperCase() 
text.toLowerCase() 
text.trim() 
text.charAt(6) 
text.indexOf("script")
text.replace("Java", "ECMA")
text.slice(1, 5)
text.concat(" is awesome!")


Math Object functions

The Math object in JavaScript is a built-in object that provides properties and methods to perform mathematical operations such as addition, subtraction, rounding, finding square roots, and generating random numbers.


Math.PI 
Math.sqrt(25) 
Math.pow(2, 3) 
Math.abs(-10) 
Math.ceil(4.3) 
Math.floor(4.9) 
Math.round(4.5) 
Math.random() 
Math.max(10, 20, 30) 
Math.min(10, 20, 30)
